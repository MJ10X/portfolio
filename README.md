# Portfolio

## Development

```sh
bun install
bun run dev
```

## Scripts

- `bun run dev` — start the dev server
- `bun run build` — build for production
- `bun run preview` — preview the production build
- `bun run lint` — run eslint
- `bun run format` — run prettier

## Built with

- TanStack Start
- TypeScript
- React
- Tailwind CSS
